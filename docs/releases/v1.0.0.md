# DSHA 诊断版 v1.0.0

首个诊断版。应用内版本号为 `1.0.0`，Android 构建号为 `206`。

## 这一版的变化

- 启动后直接显示原生聊天界面，运行环境在后台准备。需要排查时可从侧栏打开运行环境、诊断或启动日志。
- 聊天统一使用 DeepSeek API。模型列表只显示模型名称，思考强度滑杆位于模型名称下方。
- 「账号与 API」分别管理账号登录和 API Key。支持从侧栏头像进入设置。
- 原生聊天消息列表会过滤运行环境生成的内部上下文。聊天内容和历史会话可在首页查看。
