# 原生聊天思考入口与输出渲染修订

基线：诊断版 build217，提交 `50b9b4d`。这是源码候选；本次没有生成或验证新 APK。

## 修改

- `NativeChatTranscript` 的流结束帧不再立即丢弃待交接的思考。对应持久消息接管后清空；新 attempt、快照和轮次结束仍分开处理。已提交的纯思考工具步骤在等待最终回复时继续可见；中止且只有思考的轮次保留可读记录。
- 思考入口改为无胶囊边框的「箭头 + 思考过程」。向右表示收起，向下表示展开；点击区域高 48dp，保留无障碍标签和展开状态。历史重绘和流式消息交接保留用户已展开的选择。
- 原生消息列表保留相同消息与事件序号的前缀。新增消息只构建后缀；用量、附件等页脚更新不重建正文。计时变化复用已经格式化的正文视图。
- 逐条应用协议事件，合并显示请求到 50ms 窗口；持久事件立即显示。切换/暂停/销毁撤销旧显示任务。
- 思考专用记录使用独立的负序号，不把后续消息的复制/分叉/反馈操作绑定到错误事件。

这些修改作用于原生聊天页。未改变 Web 聊天前端、模型连接方式、上下文或 API 请求。

## 验证

- JVM 定向测试：`NativeChatTranscriptTest`、`NativeChatRenderPlanTest`、`NativeChatRenderQueueTest`、`NativeChatDetailsTest`，共 26 项通过。
- 在修改前复现了流先结束、纯思考工具步骤、纯思考中止三项失败。补充了结束顺序、结束后的非法 chunk、重试隔离、快照恢复和消息操作序号测试。
- 消息更新计划验证 100 条历史追加时保留 100 条；显示队列验证 100 次请求合并成一次最新状态刷新。这是逻辑验证，不是 Android 帧率或真实耗时测量。
- 10 个变更 Java 文件通过 Java 17 语法解析；箭头 vector XML 解析通过；`git diff --check` 通过。语法解析不代替 Android 编译。
- 已补充 Robolectric 的真实面板视图复用/展开状态、箭头点击与触控尺寸回归。执行 `:app:testStandardDebugUnitTest --tests '*NativeChatMessageActionsTest'` 时，在下载 Gradle 9.3.1 阶段报 `Network is unreachable`；Android 界面测试未执行，完整应用未编译。
